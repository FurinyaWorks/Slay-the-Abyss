## Description

<!-- SECTION:DESCRIPTION:BEGIN -->
P0 技术阻塞：千星原生 V25 组件方案减少了运行时逐图元组装及选角阶段新增控件，却将大量原生模板在启动时整批挂载；不能把部分页面更完整当作启动、菜单、连续战斗与手机性能全面变好。建立统一的组件级按需准备、完整呈现、有界复用/销毁、句柄缓存失效与可重复性能回归机制，保留真实 V25 视觉与既有 Lua Run/Combat 规则，不以简化皮肤冒充成功。

范围仅为 M7 组件性能架构和可观察性；真实设备 FPS 验收复用 M8 TASK-4.21。#565 已关闭未合并，本轮接续其 ae716926 已提交实现，保留原工作树的未提交皮肤改动；#580 登记由 #579 吸收关闭，运行时唯一接续入口为 #582。既存最终 V25 视觉重建由 TASK-103 跟踪，但本任务必须证明性能整改未降低现有 V25 来源品质；不得另建竞争 UI 框架或重复开发。
