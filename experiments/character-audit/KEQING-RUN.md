# 刻晴三房逐动作研究旅程

复用冻结 paid-choice 模型的 createChoiceSession、createBattle，以及 rewards.offerReward/acceptReward。单战动作仍由同一模型执行；043/044先实际支付/抽牌后等待玩家显式选择，不自动策略代打、不重放窥牌。只读公开视图，无牌堆/RNG。

默认沿用已有研究敌人 solo(45HP/8意图)、pair(24HP/6各两只)、armor(45HP/18甲/10意图)，依此三房。这是新增串行研究路线，不是正式地图、自然平衡或既有反事实报告的结论。初始10卡与遗物；每场胜利前两房显示两个候选。`k REV 1或2`领取或`n REV`跳过，均立即开下一房。生命继承，重建战斗重置能量/雷楔/附魔/Power/遗物触发，永久卡组继承；消耗牌下一战回来。没有治疗、商店、升级、存档、撤销或重开。

外层revision跨房单调，选择token含房间。重复领取、旧revision/旧token、待选时结束或领奖拒绝。先成功构造下一战才提交卡组/房间；失败不吞奖励。末房胜利为complete，死亡为defeat，均不能继续动作。进程内不可序列化续体，退出丢失当前研究局，不宣称持久恢复。

测试人工1HP房用于奖励/继承/终局分支，另注入下一房构造失败及致死敌袭；这不是正常难度通关或自然取得证据。共享入口独审待完成，全部来源/命名/平衡/真人门禁保持HOLD。
