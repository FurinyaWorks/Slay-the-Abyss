# 0.9：一次性启动、选择扩展与弃牌回收（25/75）

本批3张，不为整齐数字填充。23/24/25都使用每场一次的消耗生命周期，但职责分别是保留能量启动、一次性扩大手牌选择、已经使用核心后的再兑现。01–22数值和初始10张不变。

|ID|基础 → 升级|决策差异与风险|
|---|---|---|
|23|0费，蓄2、消耗 → 再加格挡3|不占能量启动，相比06/09不能随洗牌重复。零费满蓄可能抹平等待成本，须研究首次兑现/对照遗物；本批不宣称平衡|
|24|1费，抽3、消耗 → 抽4|比07多抽1但一次性。正在结算的卡尚未进任何牌堆，不能空库抽自己；手满停止抽取，无能量生成|
|25|1费，从弃牌堆拿第一张03、消耗 → 0费|与10只搜抽牌堆区分；必须箭曾弃置，不能解决开局牌底，空目标照付费消耗。升级零费且保留箭升级，存在爆发风险，但消耗限制每副本仅一次，不能当作无限循环|

消耗字段exhaust为布尔型；效果全部完成后移入exhausted而非discard。不是减生命、永久删牌或跨战销毁。新战斗仍由给定卡组创建，实验不包含永久卡组交易。seek_card新增显式zone=discard；省略zone仍只查draw，保持10行为。只允许draw/discard，禁止回收已消耗核心。

## 可得性审计回应与试玩路径

默认终端仍只使用初始10张，05以后并非自然奖励可得。当前所有候选可用下列**人工试验牌组**覆盖：

`node experiments/characters/ganyu/play.mjs 37 --candidate-all`

该模式每个候选一张、正常抽洗、会显著改变卡组分布；只是人工逐卡试玩入口，不是正式奖励池、自然构筑或75牌完成证明。默认模式无变化。CLI明确显示该区别。自动测试中的普通抽取可达同样只说明给定卡组可抽，不等于自然获取已交付。后续正式获取链仍HOLD。
