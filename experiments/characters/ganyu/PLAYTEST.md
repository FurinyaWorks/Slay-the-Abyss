# 甘雨统一试玩指南（隔离研究版）

## 获取与启动

在本仓库 `feat/ganyu-skill-sample` 分支的**独立检出目录**运行，勿切换他人正在使用的工作目录。需可用 Node.js（支持 ES modules 和 structuredClone），无需 npm 安装、账号或联网运行。

从仓库根目录：

```sh
node experiments/characters/ganyu/play-run.mjs 37
```

种子必须为 1–4294967295 整数；不填为37。不要双击 `.mjs`，在终端执行。退出后不会自动保存，可记下种子及输入重现。此入口已经做自动测试和独立技术复核，**尚不等于真人完成体验验收**。

## 一轮怎么操作

1. 先看自己的能量、蓄力、雨场和敌人当前意图。
2. 输入手牌序号；单体牌还需目标序号，例如 `3 1`。牌号是当前手牌位置，不是卡ID；出牌后位置会变化。
3. 输入 `e` 结束回合；未用能量会按初始遗物转换为蓄力（上限2）。
4. 胜利后输入 `o` 查看三选一。输入 `1`、`2`、`3`领取；`s`只暂关，仍可`o`重开相同选项；`p`进入下一房，不领取也能继续，成功进入后旧奖励失效。
5. `q`退出。错误命令会被拒绝，不支付资源或改变状态。

默认真实初始10张研究卡组，不预放75张；奖励领取进入持久卡组，下战会混洗并有机会抽到。不是每场或每轮都能抽到奖励牌。路线4房、生命保留、无治疗，选牌/跳过及出牌都由玩家决定。不是生产地图、正式奖励稀有度分布或完整游戏客户端。

## 查阅全部候选（与获取体验分开）

```sh
node experiments/characters/ganyu/play.mjs 37 --candidate-all
```

这是75张各一张的人工大牌组单战，不能保证快速看到每张，也不能代表正常构筑。完整基础/升级单源数据在`cards.json`，技术验证命令：

```sh
node --test experiments/characters/ganyu/*.test.mjs experiments/characters/ganyu/pressure75/policy.test.mjs
```

升级版本由自动基升测试覆盖；四房奖励当前不提供升级服务。没有正式动画、正式卡名、地图、存档或设备适配验证。

## 统一反馈重点

- 满蓄等待与兑现：核心箭在牌底、卡组变厚时是否难以兑现？
- 单蓄兑付/持满增益：是有意义的取舍，还是反而不想放核心箭？
- 冰雨建立、续场和37拆雨集中：是否符合人物和操作直觉？
- 抽牌、检索、保留：有没有同类过密、免费循环或实际难以支付？
- 受伤和选牌：记录房间、种子、卡ID及输入，而不只写“强/弱”。
