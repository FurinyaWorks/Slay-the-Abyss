
## 统一人工试玩入口：四房获取研究链

`node experiments/characters/ganyu/play-run.mjs 37`

默认10张初始卡与遗物，由真人选择出牌、目标及战后三选一；持久牌组进入下一房，HP跨战延续。战斗输入牌号和可选目标号，`e`结束回合；奖励`o`打开/重开，`1`至`3`领取，`s`暂关不销毁，`p`成功进入下一房后旧奖励失效，`q`退出。所有错误保持原状态，领取后不能重复领取。

采用audit75同一温和四房形状，默认种子37，可更换正整数。此入口没有自动策略代替玩家；仍是隔离研究奖励、固定敌人/无恢复路线，不是正式游戏地图、稀有度规则或自然平衡通过。没有存档功能，退出不保存；记录种子及操作可复现。不会改44原值或启用未批准替代数值。用于收集统一试玩反馈，而不是声称已有人测通过。原单战play.mjs及人工全池开关继续独立保留。
