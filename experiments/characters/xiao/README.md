## G2 机制合同

只有一个专属状态：面具剩余回合数0–3，无愿力、无第二计数器。进入时先失去2生命（支付后至少保留1），取剩余时长与本次时长较大值，不累加。面具期间每个攻击效果+4；x05从单体变为群体。回合末先失去2生命（无视格挡，可致死），后剩余时长−1；没有暗藏保底。状态清零不返还生命、能量或抽牌。胜利已经成立不再收回合末生命，玩家死亡不可再行动。

结算：校验阶段/卡索引/能量/生命/目标 → 复制输入 → 支付能量 → 移出手牌 → 按效果数组顺序结算 → 弃牌或消耗。取消、非法目标、费用不足、未知效果异常均返回完整原状态副本；不存在先赠资源再检查。x06为0费但占抽牌且消耗，不能循环使用。最大手牌10，出牌先腾空自身槽位；超限牌不从牌堆移走。

`endTurn` 与 `startTurn` 由phase守卫，重复调用不重复收费/抽牌；中间敌方行动明确尚未实现。只允许从enemy阶段调用startTurn是夹具边界，不等于敌方AI完成。

### 相反局面（明确夹具，不是胜率）

1. 三能量、两敌均10HP、手持 x04+x05+x01、70HP：先x04再x05对两敌各10，支出2生命、2能量，立即胜利。先常态x05仅打6单体，无法同预算清两敌。进面具有价值。
2. 3HP、敌30HP、手持x04+x05+x06：开面具降至1HP，不能本回合击杀时若结束即死亡；x06退出保住1HP但本身占一张牌且消耗。不开面具保留生命/能量用于防守的选择有价值。此处不假装已模拟敌人造成的后续伤害。

牌序不追溯：x01→x04为6伤；x04→x01为10伤。连续重开面具仍付2生命和1能量，无叠100回合套利。基础2回合与升级3回合不是单向无代价增强：升级提高窗口也多一轮潜在失血，G5需专门评估。
