## 本次修什么

- 找回胡桃标志性的“吃饱喝饱，一路走好！”元素爆发语音并分两张不同职责卡使用：「吃饱喝饱」=治疗与防御；「一路走好！」=有梅香目标单体终结。**均是官方语音截取，本作游戏机制改编，不是独立的官方技能名。**
- 对完整75张建立出处类型与N-GATE初审；实际更名15张，并更正“顺风顺水”语音出处（应该是“打开风之翼·其一”，不是“冲刺起始·其一”）。
- 版本不变量：卡牌ID、稀有度、费用、基础/升级效果、状态触发和战斗结算未改。冻结V4的 `data/original_v4/*`、正式 `src/`、线上UI和发行白名单均未改。
- **N-GATE未终审**：0/75人工批准，37张仍是原创候选，官方出处查证亦不代替效果适配/审美/全池区分批准。没有批准前不得声称完成G8/G9。

## 尚需独立决策

- **同质化**：c02与初始重击都是E期间挂梅。
- **明显数值支配**：同稀有1费付2HP的u11「踏火而行」15/19伤高于bloodshot「枪开黄泉路」14/17伤。
- **核心代价被绕过**：r06「彼岸蝶舞」无付血即可开E状态。
- **名字与命座原意偏离**：u10「伴君眠花房」本作击败挂梅目标得格挡，与原命座“队友暴击率”不同；不得冒称按原作效果。

这些是待解决的 **B/C/N3 gate**；不因改好名称就擅自修改游戏平衡、认定正式职业已完成。
