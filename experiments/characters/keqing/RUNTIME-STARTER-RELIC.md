# Starter + relic actual Lua harness (HOLD)

This is a test harness, not a newly wired game character. It composes the reviewed actual Combat starter wrapper with the reviewed pure lifecycle reducer. After a successful paid starter play, the harness explicitly dispatches the resource event once, checks both resource calculations agree, and executes any first-setup relic intent using real `Combat.block(..., fixed=true)`. On rejected play it does not dispatch a resource event. Before the wrapper's actual enemy-turn call it explicitly applies the reducer's owner-end action and checks the returned state agrees.

`runtime-starter-relic.test.mjs` passes: base and upgraded starter decks × relic enabled/disabled × three actual shuffle seeds × four actual enemy turns (48 turns); all four starter identities are actually played in each face/relic grouping. Ten-card entity count, one energy per play, input isolation, exactly one relic grant per enabled combat, matching wedge/infusion state and end boundaries are asserted. Invalid target cannot mark the relic used. Real Dexterity +10 and Frail 1 do not change the relic's fixed +4 block. Candidate values come from `statusRules` and `starterRelic`.

Player/enemy HP is deliberately 999 for multi-turn availability. This is not a survival/balance result or held-out evaluation. The controlled one-card test for fixed block is separate from the ten-card reachability runs.

Still unconnected: queued resource-effect dispatch at the true intra-card setup point; transaction-owned exactly-once emission; pause/resume owner-end ordering; a setup followed by death/reaction before later effects; production resource display/save/character registration; further powers and all 75 runtime support. Calling the reducer after an entire card, as this simple-starter harness does, must NOT be generalized to multi-event cards or called blindly for a terminal/dead player. The fixture keeps the combat alive and does not validate terminal relic policy. Shared Combat/Actor/hook files are untouched. Source/name/human/power-order/balance gates remain HOLD.
