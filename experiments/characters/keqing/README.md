## G2 时序与资源图

手牌战技 → 支付1能量 → 无雷楔时单体伤害并设置1枚雷楔 → 下一张重击或再次战技消费 → 群体即时兑现 / 单体与后续两次攻击增伤。没有每回合自动产雷楔。

雷楔0/1，不叠层；第一次设置后到下一己方回合结束清除，跨一次敌方回合。不绑定敌人身份，不因被标记敌人死亡产生悬空引用；这是本作“战场落点”改编而非原作索敌。再次战技必消费，不能刷新存储。重击在无雷楔时仍是双段攻击，避免兑现牌完全死抽。

附魔是可见的“接下来2张攻击，每段+2”，仅本己方回合有效，刷新至2，不叠加；由再次战技结算末尾获得，因此不追溯加成产生它的攻击。进入结算时快照有无附魔，按攻击牌扣一次，不按命中数或敌人数扣，已死亡目标不再受伤。名字与元素表现未批准，数据称 `infusion` 仅为内部状态。

合法性（牌在手/目标活着/能量）→ 支付 → 移出手牌进结算区 → 按结构化效果顺序执行 → 伤害逐段扣格挡并判死 → 结算后扣旧附魔次数 → 新附魔刷新 → 进入弃牌。无复制、X费、消耗、过牌；这些不支持的能力不是已测试通过。取消在合法性前返回原状态；错误抛出且不改调用方状态。所有出牌消耗手牌和正能量，无资源返还或回收边，不存在本片内无代价循环。

### 两个可达相反局面

上回合留下雷楔，当前3能量、手持KQ003/KQ004/KQ001，均基础版。

- 单敌40生命、无格挡：战技再施放8伤→重击(4+2)×2→普攻6+2，共28；先重击4×2+群体4→战技5→普攻6，共23。适合切入后接攻击。
- 两敌各12生命、无格挡：重击主目标8并全体4，主目标死亡、另敌8；再战技5与普攻6杀另一敌。反向战技8后重击第一段击杀主目标，第二段不溢出，不触发群攻；普攻8后第二敌仍4。优先引爆可消除两道敌方行动。

这是具体局部反例而非最优策略证明；对甲、多段反击、增长敌人等仍待测试。扩至75前需证明防守节奏与自然拿牌能产生该选择，不能靠固定开局送雷楔。
