## 需要实施者修正或做新证据的发现

### PRES-01 / HIGH / 确定性复制成功误报

复现：无头浏览器禁止 Clipboard API，并将 `document.execCommand('copy')` 置为返回 `false`（模拟浏览器明确拒绝复制）；点击「复制战报」。**实际**：界面仍提示「已使用本地方式复制战报。」；因为 `copyReport()` 只 catch 异常而没有检查 `execCommand` 的布尔返回值。**期望**：返回 false 时提示未复制并提供可选中的完整文本/手动复制入口，不能宣称成功。该路径用于玩家把对局日志交给AI排查，属于功能可信度问题。反例：当 Clipboard API 确实成功或 `execCommand` 返回 true 时可正常提示成功，此问题仅针对失败路径。

### PRES-02 / MEDIUM / 两张增伤牌遗漏“本回合”有效期

复现：`c14 瞧好了哦` 普通与升级、`u15 作诗一首` 普通与升级的卡面短句由 `textForOp(prepAttack)` 生成为「下一张攻击的首次命中额外+N伤害」；相同卡在技术说明 `description` 明说「**本回合**下一张攻击」。从实际引擎 `beginTurn()` 检查 `prepAttack=0`；出 c14 后本回合不打攻击直接结束，下一回合加成消失。**实际**：玩家可按短句理解为跨回合保留；**期望**：短句同步写「本回合下一张攻击」并在状态提示中明确是否仍待触发。测试：c14 基础/升级出牌后 `prepAttack=3/5`，结束回合变0。这是 UI 与实际时序不一致，不是数值应否改的争议。

### PRES-03 / MEDIUM / “完整战报”承诺不成立

`HutaoGame.log()` 每次裁剪 `logs.length` 到最多 100；`copyReport()` 却将 `g.logs.slice().reverse()` 当作「完整战报」输出。超过100条日志的五战局必然丢掉前面的事件（不含任何单独持久化历史）。**期望**：保留全战报用于复制，屏幕上只渲染最近12条；或者明确标明“最近100条”并记录已省略计数。与 PRES-01 的失败回执独立。

### PRES-04 / MEDIUM / P4 原创不是“少量”，命名来源尚未清算

按 `CARDS[*].source` 机械分类：`original=35/75`（46.7%）、`voice=22`、`constellation=5`、`skill=3`、`talent=2`、`quote=3`、`status=2`、`generic=3`。标签本身不自动等于官方逐字核验；但 P4“少量原创”的既定优先级与现有 35 张明显需要人工/设计复核。例：`c01 一进一退`、`c11 暂避锋芒`、`u07 稳住阵脚`、`u21 收放自如` 是可理解的普通短语，未见足以证实其胡桃独有表达的 P1/P2 来源。不得为了提升 P1/P2 统计而伪装衍生名为官方原文；建议逐卡记录原词、具体出处、是否片段、角色语气与效果贴合性，P4 例外写明原因，先处理重复通用成语，而不是盲目挪名。

已独立抽核一些来源，非全池核验：`r01 最不安神晴又复雨`、`r02 无可奈何燃花作香`、`red 赤团开时斜飞去`、`last 幽蝶能留一缕芳`可对照[胡桃命座与天赋资料](https://genshin-center.com/zh-Hant/characters/hutao)；`c04 撞大运咯！`、`wildfire 蝶火燎原！`、`farewell 再会啦！`、`trick 变个戏法`可对照[胡桃角色语音整理](https://wiki.biligame.com/ys/胡桃语音)。后两页为二级整理而非米哈游许可或独立官方授权证据；报告不作官方授权声明。部分来源链接只指向人物总页面，尚未逐卡验证准确锚点。
