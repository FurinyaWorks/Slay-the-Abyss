# 轻量 2D 原创几何资源来源

本实验的 `scripts/art/lightweight-2d-assets.mjs` 由项目本轮原创编写。角色的像素轮廓、色盘、矩形坐标和遗迹背景构图没有从社区 GIA/GIL、私人 Drive 或第三方角色源码复制。使用项目现有的原生白色矩形 `100001` 和三角 `100003`；这两个图库编号已见于仓库 `art/lowpoly-select/select-lowpoly.json`。平台图库的使用与分发仍遵守原平台条款，本实验不导出或公开平台原图。

角色采用金发、白衣、金岩色、披风和剑的岩系旅行者识别元素。背景保留已批准方向中的暗紫山体、暖色地平线、岩系遗迹及清晰前景，以少量大片图形重新绘制。此实现只涉及表现，未更改角色规则、数值、随机或交易。

`avatar96` 使用 27 个矩形，`battle133` 与 `lowpolyHero` 各使用 57 个矩形，`lowpolyLand` 使用 37 个原生图片控件。每份数据还会由既有运行时建立页与组容器；图元数不是原生总控件数、官方容量或手机 FPS。战斗与选角可共用造型数据，但实际实例及父容器分别计费。

## 身份字段

`artworkSha256` 为每份实际 `rows` 经 `JSON.stringify` 后 UTF-8 字节的 SHA256。每次调用均从本模块重新生成数据，不读取历史快照。

新 `bounded-2d-v1` 验证分支将角色限制为至多60图元，校验画布、ROOT与摘要格式，构建时再核对完整实际图元身份。`sourceSha256/jsonSha256/artworkSha256` 均等于本轮实际图元摘要，没有复用旧肖像摘要冒充新资源。`lowpoly-v1` 的两个入口同样使用实际图元摘要。源码、候选profile与GIL另有独立摘要及读回。

不含社区样本原始字节、解包脚本、私人链接或未确认发行许可的图片。项目许可保持仓库现有 LICENSE；该文档不扩大平台角色、美术或图库的独立权利。

本模块只声明可重建的几何和计数。待主控分别验证生成 Lua、模板绑定、GIL 写入读回、官方导入、真实 ready、逐屏视觉与 PC / Android 性能；不能用几何缩减比例宣称真实加速或完整游戏已验收。
