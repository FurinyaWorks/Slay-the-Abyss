新版初始化注册19528个 SDK 控件，随后菜单和选角阶段均无新增。旧初始化16289个，菜单新增370个，首次选角与随后120步继续动态构建，最终25697–26662个。旧构建使用真实 elapsed-time 预算，各次同120步构建进度不同；画质也不同，不能据此宣称同画质性能改善。两边本段均未离开选角，删除计数为0，不构成资源释放通过。

战斗交互另有新包实际SDK三次拖牌、敌人行动及下一回合抽牌通过记录；本次没有测战斗成本，不能据此判断跟手或完全不卡。官方设备、GPU、20次切场与最终V25视觉验收保持未验证。用户已要求先暂停主题改造，等待自行导入原组件基线。
