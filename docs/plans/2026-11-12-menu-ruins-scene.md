# 主菜单原生2D背景实施记录

**目标：** 按用户附件唯一参考，把石碑、青色裂隙、台阶、遗迹和左侧留白落实到 Simulator。

**架构：** 复用 production-25d 静态分层、V25 多边形转换和官方原生图片。背景挂到现有 menuPanel 下，不接收输入；现有标题移入左侧留白，按钮和游戏事务沿用。切出页面随原菜单隐藏，结算页单独隐藏背景。

**技术：** 原生 Image/Container、100001/100002/100003 和官方106095光效；不生成图片、不用3D、不做图像拟合。

1. scripts/menu-ruins-scene.mjs 制作五层景片，逐项统计原生图元；先通过实际 Simulator 截图检查，再压缩到约150。
2. scripts/v25-menu-layout.mjs 在原控件树接入；src/lua/abyss_v25_menu_view.lua 保证结算/返回状态正确。
3. experiments/menu-ruins-review 使用已有完整游戏归档作早期美术迭代。最终以本轮源码构建副本、读回并运行；早期投影不得当作本轮GIL。
4. 真实截图对照附件检查石碑、色彩、景深与空间关系。加载、切页、稳态和往返控件数分别测量；不能以软件截图时长当作FPS。
5. 相关验证和独立只读复审后提交Draft PR；不合并发布。官方客户端/手机未测保持未验证。
