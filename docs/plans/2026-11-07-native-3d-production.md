# 正式原生3D迁移

用户本轮已批准原生3D战斗路线并授权自主实现。独立工作树基于 develop d8a57cae；旧2D入口和PR553实验分支保留。任务记录为TASK-103；TASK-102继续维护工具及实验，不因本迁移关闭。

目标为岩系旅行者两幕连续流程。保留原GameUI菜单、选角、地图、节点、战斗卡牌、奖励、商店、事件与结算；不建立新的Run、固定种子或替代奖励事务。原生表现适配器读取当前战斗身份及已经提交的反馈事件，通过已验证的双向信号驱动场景。配置、模型、技能、脚本和完整原UI装入同一个GIL，玩家只需导入一份。

首个集成先复用553三种外观与成熟桥，支持五个敌人槽，尚非最终敌人美术验收。后续按原内部ID增加官方外观、玩家动作、特效和镜头，不能把通用外观映射计为完整美术。无原生伤害节点，Lua继续唯一负责规则、RNG、进度与胜负。迟回执、换战斗、超时和销毁时清理；缺动作时保留可操作的2D显示。

执行切片：正式生命周期适配及故障测试；固定decision及技能中断修正；静止地图颜色写入去重；完整基础候选加原生场景、源码独立读回与静态检查；独立复审、完整工程门禁；同候选官方导入、新ready、PC全流程和实体手机性能/触控验收。最后三项不能以离线夹具代替，缺项保持未完成。

已排除直接整合实验菜单（会固定重建战斗）、整体替换手牌（缺成熟动态全文输入路线）、复活旧2→1重绘优化（PR501恢复可观察边界）。原生奖励选择器保留备用，当前完整奖励UI继续使用，避免引入未验收的动态库限制。
