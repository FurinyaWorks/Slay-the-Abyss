# 主菜单画质与资源重做计划

用户明确要求继续优化美术、性能和资源，不接受上一版1598图片的质量。本轮继续原任务与隔离工作树，保留原生素材拟合、双按钮、原图构图。

1. 复现旧轮廓过度简化、重叠面部ROI和逐三角容器的成本。保留旧数据及截图为同条件基线。
2. 按用户后续确认采用约1500–1600绘图图元、上限1800的预算。比较边缘引导网格和分部位轮廓分层，以整体与面部误差及轮廓/眼睛实拍筛选，不把数量下降当作画质通过。低图元探索只保留为拒绝方案。
3. 复用既有单轴原生三角放置，剔除逐图容器；验证顶点几何与原生读回，禁止通过松动门槛或纹理导入伪装改进。
4. 对同样式归档进行仅菜单背景替换，记录背景/全应用节点、字节、实际SDK初始化、缓存返回和内存；独立无头实际渲染与hover检查。性能测量和截图分开，未测的官方GPU/设备保持未验。
5. 独立复审后才将明显改善候选接到原地址，保留回退。完整要求未达到则继续任务，不以诊断或预览通过宣称美术/性能全达标。

已采用方案比较与系统诊断技能。本计划在用户已授权的原有目标内细化方法，不引入新的产品范围或授权步骤。
