## 已复现的问题与修复

`local function init() return require("b") end; pcall(init)` 在模块加载过程中同步执行 init，但原初始化分析只看到 pcall 的全局标识符，没有访问它的函数参数。若 a→b 登记了仅供后续回调使用的 deferred 例外，真实初始化环 a→b→a 就被漏过。xpcall 的被保护函数和同步错误处理器存在同样缺口。

本次复用已有词法作用域、单次赋值解析和 owner 调用闭包，只把直接全局 pcall 的首参数、xpcall 的首参数及显式第二参数加入候选调用。没有新增扫描器、运行库、配置例外或游戏状态。未调用函数里的保护调用仍属于原 owner，不提前激活；其他参数中的函数值、返回的回调和局部遮蔽不误作调用。
