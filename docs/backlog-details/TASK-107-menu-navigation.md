# TASK-107 菜单导航与会话恢复

基线：`origin/develop` 的 `9f2f44e4c79789fbcb64a515938765dbc240f830`。独立分支 `feat/menu-navigation`，不包含根工作区或其他美术 PR 的未合改动。

原版依据：[2018-03-15 Weekly Patch 16](https://store.steampowered.com/news/posts/?appids=646570&enddate=1521736421) 的 UI and Effects 将局内 Save and Quit 改为返回主菜单。本项目不提供跨奇域会话存档，按钮使用「返回主菜单」「继续本局」，并明确退出奇域后无法继续。

## 行为

- 局内菜单提供继续游戏、查看地图（适用时）、返回主菜单、放弃本局、退出游戏。未开始或已结束本局时收起会话入口，原退出位置显示「退出游戏」。保留操作说明及空白关闭。
- 返回主菜单保持原 Run、Map、combat、nodeFlow、奖励和随机流；`sessionPaused` 停止计时、战斗反馈及房间更新。继续时按原状态恢复页面，不重建本局。
- 放弃本局需要确认，确认后清除当前会话本局并返回主菜单，不提交平台退出信号。开始新游戏若覆盖未结束的本局，也先确认；确认后原进度清除并进入选角，取消确认保留原进度。
- 主菜单和局内的退出游戏复用平台结算请求；失败可取消或重试，成功后锁定输入防止重复提交。已获胜结果保留胜利，未结束本局退出不伪造胜利或修改生命。
- 复用V25菜单字体、菱形/高亮状态及既有背景。新增继续入口置于开始游戏上方；暂停菜单按可用行收起空隙，主题参数由 `ui_theme.json` 生成。
