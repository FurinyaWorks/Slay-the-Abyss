# 命名、出处与角色文案

入口见 [PRODUCTION](PRODUCTION.md)，原始范围见 [MIGRATION](MIGRATION.md)。本页合并 N-GATE、SOURCE-GATE 和 v2.1 的 L01–L22；不改变任何卡牌ID、费用、效果或升级。以下是生产审查规范，不代表检查已自动接入CI。

## N-GATE：先有职责，再选名字

| 编号 | 放行要求 |
| --- | --- |
| N0 先效后名 | 先明确卡牌类型、战术用途和真实规则，再找合适名称；不拿故事段落硬配效果。 |
| N1 来源优先级 | **严格按 P1→P2→P3→P4 顺序检索**：P1 官方技能/天赋/命座/七圣召唤/战斗语音；P2 官方故事/任务/日常语音/宣传；P3 有可靠出处且与角色动作相关的现实武术/文化术语（低优先级）；P4 少量原创。使用低优先级必须留更高来源检索及否决证据；等级本身不代表合格。详见 [SOURCE_PRIORITY](SOURCE_PRIORITY.md)。 |
| N2 自然度 | 名字须是完整、自然、有独立意义的名词、动作或招式短语；拒绝叙事残句、语法不通和词根拼贴。自然的正式长技能名可以保留。 |
| N3 不误导 | 名字不应与用途矛盾，但不必直述伤害、格挡或资源兑换。合适的官方意象可保留，不能仅因不够字面就替换。 |
| N4 角色风格与卡面感 | 语气、世界观和招式感要像**该角色的玩家技能**，而不只是准确的武术教材动作/专业词条；不能因为 P3 有出处就直接展示「舞花枪」等原词。人审须判断角色独有性、玩家可理解的动作表现和能否与同池同义技能区分。 |
| N5 来源与卡面名身份 | 完整技能名、语音原句/截取、故事摘取、现实术语和本作改编名称必须**分别标注**。P3 技法资料先作动作参考；如再创卡面名，写 P3参考＋本作改编、不得宣称技法原名；少量使用原词的例外须独立批准。精确记录原文、语境、链接，不随更名覆盖旧出处。 |
| N6 全池区分 | 检查同名、同音、近义堆叠、关键词重复和攻击/防御语义混淆；重要招式保持清晰且唯一的辨识位置。 |
| N7 四关齐过 | 自然顺口、效果不误导、角色风格正确、来源身份真实或明确原创，缺一不可；官方出处和稀有度均不能豁免。 |
| N8 失败处理 | P1 不合格先查其他 P1，再到 P2；P3 只有官方无合适名称且现实技法真正贴合时才考虑；P4 必须交代官方及现实来源不适用的原因。无合格名则保留唯一“待命名·ID”，阻止正式准入；不得凑75张带病发行。 |
| N9 双层审核 | 机械检查ID/名称唯一性、必填来源和已知错误；人工评审自然度、语义、气质及全池区分。通过须有审核者、日期和证据，单个PASS无效。 |
| N10 单一母表 | 当前名称只维护一份；历史来源基线和更名日志独立保留。旧导出不得反向覆盖已审数据。 |

典型拒绝例：“斩魔神降异族”即便可追溯到故事，也不能据此放行叙事残句；“再接我一刀”用于回收消耗技能会产生效果预期错位。“受流/居合/纳刀”等现实术语不能伪标成原神官方技能。“须臾之梦”不必改成直述资源兑换的泛化名称，只要自然、贴角色且没有明显误导。

## SOURCE-GATE：出处与更名控制

| 编号 | 要求 |
| --- | --- |
| S1 原文先行 | 每张先按稳定ID、实际效果查 P1 官方条目，记录具体原句、精确出处、语境与版本，再逐层检索并留下不用更高来源的原因；只贴人物主页 URL、来源类别或“官方语音”不足以逐项核验。 |
| S2 保留优先 | 已有自然、符合角色且不误导的官方名优先保留；改名必须指出真实缺陷，而非仅追求直白。 |
| S3 变更留痕 | 改名前保留卡牌ID、旧名、旧出处、新候选、新出处、原因与审批；批准后更新当前数据，历史记录不覆盖。 |
| S4 一致性 | 当前名称、来源类别、原文和链接与已核基线一致；变更差异和人工审查缺失均不能放行。旧Sheet的U/F/Q/T列是旧实现位置，不是新数据契约。 |
| S5 工程边界 | Sheet公式和警告不等于不可绕过的保障；自动阻断需要实际版本化基线、审查记录、坏样本测试与生产/CI接线。本次迁移未实现它。 |

逐卡至少记录 card_id、decision_role、effect_ref、name、source_tier(P1–P4)、source_kind、source_text、source_locator、source_version、source_context、source_verified、P1/P2覆盖情况、更高来源否决记录、P3适用性、N2–N7结果、审核者、日期和证据。P3还需原词/专业出处/真实动作/实际效果映射，P4需官方检索及P3不采用原因。更名不动机械数据并保留全部历史。字段语义可沿用现有结构，实际自动CI为后续独立工程PR，本次迁移不冒称已接线。

## 优先级审查顺序

**先官方，后文化，最后原创；但不能直接照抄文化原词。** P3 文化术语是低优先级的动作/命名研究材料，不是解决官方词库不足的词条替换器。真实术语和面向玩家的卡面名称应分开记录；默认只能作动作参考，角色化名称另过 N2/N3/N4/N6。雷电的居合/受流/纳刀等现实刀术不能冒充原神官方名；胡桃的真实枪术术语只能用于确实对应的枪法动作，不得用枪术名给纯过牌/治疗牌贴皮。任何来源仍必须分别通过 N2 自然度、N3 贴效、N4 人物、N6 全池区分及人审。

严禁只凭名字不重复、有 source=original 字段、人物主页 URL 或75/75填满就报告命名完成。见 [SOURCE_PRIORITY](SOURCE_PRIORITY.md) 的逐卡降级留痕与反例；胡桃当前「夜路照明」「掩袖回枪」「顺势点梅」属于未经证明的原创建议，不得放行。

## L01–L22：人物与文案审查

| 编号 | 规则 |
| --- | --- |
| L01 | 官方游戏内故事/语音/技能与官方发布优先，社区整理如实标识；不拿梗或评论当正史。 |
| L02 | 准确使用官方中文名称，并明确本作回合制改编；不冒称沿用官方倍率或原动作机制。 |
| L03 | 锁定剧情时点、说话者和身份；未知时不写依赖特定阶段的断言。 |
| L04 | 参考角色句型、语气和动机创作，不把新写台词标成官方原话或录音。 |
| L05 | 机械效果短而准确，风味独立字段；不能用诗意遮盖费用、时机、目标或条件。 |
| L06 | 二创意象仅作适度彩蛋且不冲突正史；不能默认第三方图文、台词或配音可复制使用。 |
| L07 | 故事指向保留事实与位置，优先原创概述；不大段搬运受保护的原文和演出。 |
| L08 | 平台音频须记录实际资产ID与可用范围；无可用授权证据时采用原创或自制替代，不默认可拆包上传。 |
| L09 | 胡桃可俏皮，但处理生死与仪式须负责、尊重，不写成恶意嘲弄死亡。 |
| L10 | 阿蕾奇诺兼具外交/执行官身份与守护者责任，不把整套表达窄化成追债商人或伤害孩子的爽点。 |
| L11 | 芙宁娜的舞台表达、脆弱和自主选择按剧情阶段处理，不永久当现役水神，也不拿旧创伤取笑。 |
| L12 | 区分影与将军人偶的人格、语气和时点；不能随意互换甜食撒娇与冷酷机器式刻板印象。 |
| L13 | 全卡池审身份、战斗、故事、日常与词汇情绪层次，不能逐张无明显错误就宣布整体通过。 |
| L14 | 文案/人设与数值是独立审查；修OOC不构成修改资源支付、触发顺序或数值的批准。 |
| L15 | 自动初筛、人工审美、卡面实测和来源/使用范围核验分别留痕，未执行不能写已通过。 |
| L16 | 背景判断记录来源版本和剧情时间；新旧内容冲突保留证据，不用旧语音武断覆盖后续明确剧情。 |
| L17 | 建议写作顺序：人物身份与战斗动机→官方/原创词→中文效果→短风味；不先堆诗词再硬接机制。风味默认控制为一行，但按实际界面审核。 |
| L18 | 生产前文案复核，敏感剧情再查角色约束，试玩收集角色感；每项调整保留ID、原因、来源及前后版本。 |
| L19 | 名字可来自动作、情境与说话方式；格挡等机械内容写在效果，不因有防御就强加“盾/护”词缀或暗示原作护盾。 |
| L20 | 原创名可优先常见短名，但不是硬性字数门禁；允许自然短句和完整官方长名，不强凑古风四字或生僻对仗。 |
| L21 | 各角色有自己的表达层次，不让所有人共用同一种文言格式。新角色须另立来源支持的人物约束。 |
| L22 | 仅更名时机械语义diff必须为零；稳定ID与所有引用保持正确，费用、伤害、状态、触发、升级不随新名改变。 |

人物约束是本项目编辑规范，不代替持续的原文核验。特别是原“V5 命名来源基线”多项标注未逐条核验，迁移不会把这些项自动变成已核。

## 审核交付

每张候选保留四关结果与未决项；全池另给相似名称/风格分布评审。AI可先筛候选和找反例，但不能把自己的评分等同用户的审美批准。没有合格名称或出处时，保留缺口比编造来源更好。
