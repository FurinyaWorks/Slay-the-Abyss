# 角色卡牌名称：来源优先级与降级证据

> SOURCE-PRIORITY v1，承接 [NAMING](NAMING.md) N-GATE/SOURCE-GATE 与旧雷电 V5 SOP E5「文化命名」。**现实文化来源优先级低**，是必要时的补充，不能取代官方资料检索。本规范适用全部角色。

## 来源优先级（查找顺序，不是自动合格评分）

| 级别 | 来源 | 合理使用范围 |
| --- | --- | --- |
| **P1 官方战斗来源（首选）** | 原神正式技能、普攻/重击、元素战技/爆发、天赋、命座、七圣召唤，以及战斗语音原名与自然短句 | 完整正式名优先；要贴卡牌职责与原作身份，不照搬倍率或硬套词语 |
| **P2 官方人物来源（次选）** | 有定位的角色语音（非战斗）、故事、任务、角色演示、官方宣传 | 必须自然独立成句、语境与角色契合、卡牌职责不矛盾；不能拆故事残句 |
| **P3 现实文化/动作（低优先级）** | 有真实出处且和角色武器、动作、身份直接相关的枪术、刀术、礼俗或技法 | **首先是动作/演出/命名创作参考，不是直接可用的玩家技能名清单**。P1/P2无合适名称才引用，记录原词、专业出处、动作含义与实际技能映射；选择最终显示名仍须走角色表达审查，不能假称官方招式 |
| **P4 少量原创（最后兜底）** | 有清晰动作或角色语境的本作新名称 | 记录 P1/P2 不适合、P3 无关/不适用或证据不充分；拒绝随机拼「梅/灯/蝶/火」 |

**基础通用牌特例（SYS，不是新的优先级）**：已固定的「普通攻击」「防御」「重击」可以作为共享系统牌使用，使用SYS身份记录，不需要为“普通攻击”强行查某角色的P1-P4专属词汇。这只适用于经批准的通用基础牌，不能用SYS为任何新增角色技能、非基础奖励牌或原创命名绕过官方优先检索；最终卡面仍要检查玩家预期。

**重要区别**：真实技法是“动作资料”，不意味着其专业名称是“玩家看见的卡牌技能名”；武术教材、枪术训练条目直接当招式名，往往缺乏角色独有的气质和表现力。来源可靠 ≠ 这个名字自然 ≠ 这张牌合适。高优先级官方名也要通过 N2 自然度、N3 贴效、N4 角色风格、N6 全池辨识；如果不适合必须记录原因继续查下一个。P3 即使是真的武术术语，也不能强行套在与动作无关的防御、过牌或回血牌上。

## 关键分层：技法参考 ≠ 卡面技能名（2026-11-13纠错）

原流程的失效点：**查到正规枪术动作 → 觉得它和伤害/格挡有一点关系 → 直接让卡牌显示「舞花枪」「扎枪」「拿枪」**。这叫技术术语搬运，不叫角色化命名。旧校验只检查 `source.cultural.original_term` 与链接存在，**没有要求`display_name`与资料参考区分**，即使只有 PENDING 也能出现在试玩网页。

**来源优先级 P1→P2→P3→P4 不变，但这是“证据检索优先级”，不是“照抄原词的命名优先级”。**

对使用 P3 的卡，必须拆出三个不同字段：

| 层级 | 举例 | 含义 |
| --- | --- | --- |
| `source.cultural.original_term` | 舞花枪 | 真实技法/专业动作原词，留在内部研究索引 |
| `action_design` | 枪身贴近身体绕圈，表现范围攻击和回防 | 原词怎样实际支持动作设计；没有动画证据不得冒称已演出 |
| `name` + `source.name_method` | 待命名·u19 + `reference_only` | 玩家看到的候选名称与命名方法独立管理，未经审稿不把技术条目填成卡牌名 |

P3 对最终卡面名只有三种有效处理：

1. **reference_only（默认）**：技术资料已经验证，但还没有角色化名字。只展示唯一「待命名·卡ID」；引用该技法做动作/演出研究。这是正常待审状态，不是新增失败数量凑分。
2. **cultural_adaptation（常规）**：参考真实动作，但另创自然的、有胡桃自身节奏与辨识度的卡牌名；标注“真实技法启发＋本作改编名称”，不得冒称武术原名或官方技能。必须解释从真实动作到**卡牌表现、人物气质、同池区分**的对应关系。
3. **literal_exception（极少数）**：仅当原词本身确实就是合理的玩家技能名，动作在游戏中可识别、卡位区分足够，并获得独立人审的具体书面例外批准时，才允许直接使用真实术语。可以有「纳刀」这样的特例，但不是“凡属官方武术术语都可照搬”。

**玩家视角检查（人工强制，自动化只验证记录）**：请不看出处读卡面名：①听起来是胡桃的卡，还是任一持枪角色的基础训练？②能否想象它在战斗中承担该牌的主要动作，而不是硬解释低血抽牌？③同池是否还有多张「枪」基础术语导致不易辨认？④官方名称若符合效果为什么不用？这些问题没有明确答复、审美批准或可看画面时，必须 HOLD。

**一眼就该退回的反例**：`舞花枪`（真实枪术动作→不能直接作为胡桃罕见群攻的技能名）、`扎枪`、`拦枪`、`拿枪`、`崩枪`、`点枪`、`挑把`、`拦拿扎枪` 均属此次实际误用。保留真实资料，撤回卡面命名，不能在“查到了资料”的同一轮给 N4/N6 打勾。也要检查剩余 P2 原句和 P4 原创是否真有角色感，不能因为不在 P3 就自动通过。

**程序硬约束**：P3 资料记录须显式 `source.name_method`；`reference_only` 不得展示技法原名；与 `original_term` 标点归一化相同的卡面名默认拒绝，即便标了 PENDING。例外须另记 `review.literal_exception` 的理由/人物性格/全池区分/审核者/日期/证据；`cultural_adaptation` 须有 `display_derivation` 和人物风格审查。只有独立N-GATE人审可定稿，不能让LLM自己填这些字段后自己批准。

## 强制的角色资料准备

在命名任意卡牌前，先建立版本化官方资料索引：角色与剧情时点、技能/天赋/命座/七圣召唤/战斗语音/日常语音/官方故事/官方宣传各类是否查询；每个收集到的锚点记录正式原词、精确条目或语句定位、语境、版本和核验状态。只给角色主页链接不算精确来源。

P3 术语库独立于官方锚点库；须明确现实技术/文化来源与动作含义。雷电可在严格降级后考虑「居合」「受流」「纳刀」等真实刀术，不能误标官方；胡桃若需补枪术也要先有相关真实攻击动作，不能把「扎枪」给纯过牌卡。无相关技法时 P3 可以标 not_applicable，不许为了完成表格强行找文化名字。

## 逐卡来源审查合同

每个稳定卡位先写出类别、实际效果、战术职责，再寻找名字。审查记录必须包含：

- card_id / role / decision_role / effect_ref / name / source_tier / source_kind
- source_text / source_locator / source_context / source_version / source_verified
- p1_checked / p2_checked / p3_status (searched、not_applicable、unknown)
- higher_priority_rejections：每条指向更高层级真实检索候选，说明不适合的 N2/N3/N4/N6 原因；P2 须有 P1 的检索/不适合记录，P3 须 P1 与 P2，P4 须 P1/P2 并说明 P3 的状态和理由
- P3 附加 original_term / cultural_source / real_action_meaning / mechanic_mapping
- **P4 进一步强制**：每张必须先填动作语境（武器攻击／武器防守／武器连击／纯过牌／非武器防御／治疗／状态术法／叙事能力）。若本牌确有枪、刀等实际武器动作，P3不能简单写 `not_applicable`：必须检索至少一个有出处的真实技法候选，记录原词、专业来源、真实动作意义和逐项否决理由；只有确实没有对应的真实术语才允许走P4。若是抽牌、回血等无武器动作的牌，P3可记录 `not_applicable` 以及具体不适用原因，**不能用枪法给非动作牌贴皮**。程序门禁只检信息完整、不能替代独立人审
- n_gate（N2/N3/N4/N5/N6），human_review（reviewer/日期/evidence/批准状态），old_name/source/change_reason 审计；对同池名称重复、词根堆叠及相同职责卡并行复查

审核者必须能沿稳定ID追到：**高优先级官方检索 → 不适合的具体候选和原因 → 当前候选的出处与语境 → 卡牌效果对应 → 独立审核**。不能只填「官方名字已经找过」「这是原创名字」「人物主页URL」。

**人审门禁**：来源证明只解决真实性，AI 生成的 PASS 或字段填写不能证明自然度/审美。全部必填且人工有可追溯证据才可标命名 APPROVED；若有任一卡位不合格，整套75卡命名为 HOLD。实验卡牌仍可被单独执行测试，但不能作为完整已命名的正式职业交付。无法给出合格名字则写「待命名·卡ID」，不要瞎补。

## 反例与失败回归

| 卡位 | 错误说明 | Gate |
| --- | --- | --- |
| 胡桃 c19「夜路照明」 | 只说夜行备灯，没说明为何能转化为下回合抽牌；P1/P2 未检索/否决 | N3/N4 + P1/P2 HOLD |
| 胡桃 c01「掩袖回枪」 | 自拟“持枪进退”并非有据可查的现实枪术，也缺少 P1/P2 备选来源 | N2/N4 + P1/P2 HOLD |
| 胡桃 c06「顺势点梅」 | 只是把“点梅”拼进名字，没有官方或真实技法支持，P1/P2 缺失 | N2/N4 + P1/P2 HOLD |
| 雷电「居合/受流/纳刀」 | 仅可作为低优先级真实刀术术语，不能凭典故或术语真实就宣布官方/贴效 | P3 需专业来源和机制映射 |
| 填满75个名称、每条只有 original/人物主页URL | 缺少精确来源和降级过程，即使脚本验证ID唯一也不是命名完整 | 全池 HOLD |
