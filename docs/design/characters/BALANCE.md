# 数值、经济与仿真

入口见 [PRODUCTION](PRODUCTION.md)。本页整理 B-GATE、C-GATE 和极限/仿真方法；雷电专属版本事实另见 [RAIDEN](RAIDEN.md)。这是审查方法和历史对标快照，不是自动调参器，也不是任何职业已平衡的证明。

## B-GATE：数值变更必须有依据

| 编号 | 必须提供 |
| --- | --- |
| B0 原版固定 | 只以初代STS1作本套对标；记录职业、稀有度、基础/升级、代价和来源，不混STS2或拿稀有牌当普通价格。 |
| B1 同类对照 | 至少两张相关STS1参照，比较费用、稀有度、单/群体、即时/持续、随机/稳定及副作用；没有真正同类时明确差异。 |
| B2 单卡价值 | 基础伤害、每能量收益、击杀阈值、格挡/过牌和职责用于诊断；不能因不带联动就凭感觉加伤。 |
| B3 机会成本 | 在约定能量/手牌环境中与同回合替代组合比较，前置可支付且有可达的价值场景；2费前置+2费本牌不能冒充常规3能量内可用。 |
| B4 额外资源 | 计入专属资源、状态、占手、抽牌、启动和延迟成本；比较0/中/满资源、无/有状态及不同牌序。 |
| B5 升级 | 检查伤害、费用、过牌、持续或机制改善的真实收益及循环风险，不默认每张+3伤。 |
| B6 同池差异 | 同费同稀有度的重复/支配关系须审，至少给两种不同选择的具体局面；基础牌和奖励牌的职责不能混同。 |
| B7 多场景 | 固定种子、多构筑、普通/精英/Boss分别记录失血、胜败、打出次数和失败原因；一局胜败不足以调整整池。 |
| B8 批准 | 已有数值按旧值→候选新值→对照→可复现测试→用户批准→同版本数据更新的顺序。新设计的初始数值也应标候选，不能伪装已审基线。 |

0费仍消耗抽牌、手牌或未来机会；高费占用回合行动预算，但不要求所有高费牌返能。纯伤害可以有明确价值，多段须按实际成长/触发通道核算。不能用统一“1费=多少伤害”替代上述比较。

## C-GATE：全池经济与可读性

| 编号 | 验收要求 |
| --- | --- |
| C1 可读公式 | 去掉无意义的1×、重复乘除和取整；枚举合法资源范围及基础/升级，展示结果与实际结算同时断言。 |
| C2 真实费用 | 按当前能量、抽牌机会和资源先决比较；昂贵的回收/调度必须解释额外收益，不能只看单牌描述。 |
| C3 支配与选择 | 同费同稀有同类型比较通常态/成型态、基础/升级；奖励牌在至少一种可达状态值得选，同时保留合理不选情境。 |
| C4 原版锚点 | 相同/近似效果可作可核对参照，须注明环境差异；不是普适上下界或照抄定律。 |
| C5 升级与循环 | 升级有明确价值；回收/复制要查同名互回、牌区、费用、触发次数与资源净流，拒绝无代价套利及程序非终止。 |
| C6 数据与界面 | 稳定ID、卡池规格、基础/升级、结构化效果、卡文和模拟输入一致，真实交互流程可完成；版本一致不等于平衡通过。 |
| C7 风险留存 | 未决警报列具体卡ID、条件、下一实验和证据缺口，不能为了清零报告擅自改值或把风险直接宣判为Bug。 |

原C-GATE v2.3的3/20/36/16稀有度分布、0–6愿力枚举及个别修值属于V5.10.2雷电样例；新角色使用自己批准的环境合同，不能把这些数当全职业常量。

## 可复现的概率与极限分析

公平无放回抽牌，牌组N张、来源K张、抽H张：至少一张来源的概率为 `1 − C(N−K,H)/C(N,H)`。已知一张收益牌在手且它不是来源时，改为从剩余N−1张抽H−1张。不能用此公式替代跨回合状态、过牌、检索、洗牌和实际支付模拟。

以N=20、H=5为例：

| 来源数K | 同手至少一来源 | 已有收益牌时其余4张含来源 |
| --- | --- | --- |
| 1 | 25.00% | 21.05% |
| 2 | 44.74% | 38.60% |
| 4 | 71.83% | 64.78% |
| 8 | 94.89% | 91.49% |

这些是同手可及性，不是出牌成功率或胜率。四张来源也不是普适合格线。单张核心牌、前两回合共见10张且不额外过牌/重洗时，N=10/20/30/40对应见到率100%/50%/33.33%/25%；保留不改变还没抽到的概率。

极限与反向用例至少覆盖：无来源/唯一稀有来源/过多来源；0/中/满资源及溢出；核心牌在牌底、过早抽到、满手；状态0/1/2/100次、持续时间远超战斗；1/多/100段、单/多目标、致死±1；零防守、恢复稀缺、连续群怪攻击；0费抽牌+回能+回收和取消重复领资源。极限不是正式游戏常态，而是用来发现边界错误。

## 仿真必须分层

先固定环境版本和独立正确性断言，再做局部合法牌序、理想构筑、自然奖励全流程、保留种子与人工试玩。普通/精英/Boss和不同敌人族群分组，区分完整/半成型、重复组件、卡组厚度与升级状态；不只测一次手工配好的强牌组。

每份报告至少包含：输入/策略版本、种子及随机流、可见信息边界、样本单位与分母、失败/超时/截断数、组件展示/选择/成型率、首次兑现时点、死抽及未支付次数、各战失血P50/P90、死亡位置、胜败和估计不确定性。多策略避免把代理不会用牌误判为牌弱；调参种子与保留种子分离。同种子只有在随机消费语义一致时才构成可比条件。

原表记载26项数学/输入断言和100,000组奖励序列抽样，后者不是100,000场战斗。本次仅迁移记录，未重跑这些实验。原表提出的576格、多种策略及大样本战斗矩阵仍是计划，不是已取得的覆盖，也不作为每次小改动强制重跑的固定规模。

## 出口

正确性、设计证据、实际体验分层通过后才能申请冻结。风险未消除则保留候选与待测卡ID；数值未经批准不改，不能通过删负例、缩窄有效场景或变更统计口径制造绿灯。
