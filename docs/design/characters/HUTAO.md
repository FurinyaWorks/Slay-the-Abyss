## G0｜角色合同：只保留能带来选择的复杂度

- **身份**：胡桃，往生堂第七十七代堂主。人物气质兼顾活泼机敏、诗意与对送别仪式的严肃尊重；不把死者当笑料，不把“扣血”理解为残酷或自伤叙事。故事阶段先用不依赖特定传说任务后续的通用人格，涉及剧情的卡文须单独定位时点。
- **一句话玩法**：**以血换火，险中求胜；为了更快结束战斗冒险压血，还是先保住生命应对连续战斗？**
- **玩家可见的三个认知点**：①蝶引来生要真实付血；②生命值不高于一半时，蝶舞强化更大；③安神秘法会回血，却可能让后续攻击离开低血档。
- **机制减法**：HP 就是资源，不加“蝶火点/愿力式计数器”；只保留己方蝶舞状态和敌方血梅香。旧版“普攻+2、前2张重击+5、低血额外+1、血梅香强度1..3”等分支不作为 V5 默认。
- **禁止项**：不造元素反应体系、不让支付生命致死、不靠必然无限回血掩盖跨战风险、不把“官方技能名称”当官方卡牌数值证明、不改当前公开职业白名单。
- **设计规模**：正式成熟规格仍以 75 张为方向，但这一轮只做11种卡牌、10张起始牌和2个相反局面；G4–G7 前绝不宣称全职业平衡/正式可玩。

## G2｜小而明确的规则合同

| 范围 | 候选规则 |
| --- | --- |
| 通用环境 | 最大HP72、回合3能量/抽5、手牌上限10，现有格挡/虚弱/易伤以实际核心为准；HP跨战继承 |
| 支付生命 | 所有强制 HP 支付先总量预检，支付后必须≥1HP；先扣能量与HP，再计算该牌条件快照。失败必须**整次原子回滚** |
| 半血档 | `2×当前HP ≤ 最大HP`；每张牌支付后确定一次条件，后续卡牌重新检查。不能用战斗开始的旧状态代替当前HP |
| 蝶引来生 | 1能量、实际付6HP，刷新`蝶舞`为2个己方结束阶段；当前回合结束包含在这2个阶段内；升级只多给3格挡，不延长持续 |
| 蝶舞 | **每张实际打出的攻击牌**首个命中活目标加3伤；半血及以下加5；只加一次，不按多段/敌人数复制。技能牌（包括安神秘法）不吃此攻击加成 |
| 重击挂梅 | 带 `charged` 标签的攻击在蝶舞中**实际扣除目标生命后且目标仍存活**，施加血梅香；被格挡完全抵消的攻击不挂梅。死亡目标不挂梅 |
| 血梅香 | 每敌最多1份；2次触发，每次固定2伤（仍先扣敌人格挡）；同名再施加只把次数刷新为2，不叠加伤害/次数；在己方结束阶段、存活敌方行动前结算 |
| 安神秘法 | 2能量、全体11伤（升级14）；至少命中过一个原存活敌人时按**施放时支付后**血档请求回复：高血4/升级5，低血7/升级8；实际回复受缺失HP与本场共享12额度限制；本战消耗，下一战恢复 |
| 遗物 | `引蝶灯`：每战首个成功的实际HP支付后获得4格挡，不因此回复生命或额外触发；测试时复用旧设计的假设值 |
| 结算顺序 | 预检 → 移牌与支付 → 唯一条件快照 → 蝶舞攻击首命中 → 顺序执行效果 → 存活目标挂梅/消费梅 → 本牌弃置或消耗 → 己方结束时血梅香 → 存活敌人行动 → 蝶舞剩余阶段-1 |
| 限制 | 不加即时回能、额外回合、无限免费回血；本战状态不跨战，HP与永久卡组跨战；未覆盖外部遗物/药水的联合效果 |

**设计解释**：这是只保留两个可见状态的角色；真正决定风险的仍是玩家的HP。血梅香可作为慢收益，也能通过「落梅收灯」提前兑现，但要放弃尚未触发的后续次数。

## 反向局面：同手牌与敌意图，选择可反转

共同条件：胡桃40/72HP、3能量；手牌为蝶引来生、重击、普通攻击、安神秘法、防御；敌人下一次攻击22。没有其他状态、护甲或额外奖励。

| 对局 | 冒险路线：E→重击→普攻 | 稳健路线：Q→防御 | 观察 |
| --- | --- | --- | --- |
| A 敌21HP | E付6HP到34，低血强化使重击12+普攻11＝23，直接击杀；自己余34HP | Q伤11、回4，再挡5，敌余10HP且攻击后自己余27HP | **这两个路线中**付血抢杀更好，敌方行动被取消 |
| B 敌60HP | 同上造成23直接伤+血梅香回合末2伤，敌余35HP；引蝶灯挡4后自己余16HP | Q伤11、回4、挡5，敌余49HP、自己余27HP | **这两个路线中**稳健路线留存更多生命，尤其要考虑下一回合与跨战 |

这是人工指定同牌序、单敌、单回合的**逻辑反例**，不是最优策略穷举。每个结果由下方脱离 Lua 的离线检查重算；不代表实际游戏结果、强度排名或玩家偏好。

附加阈值例：胡桃32HP放Q并命中，按低血请求回7 → 39HP，因此**下一张牌**会按高血档重新计算。Q的这次治疗不能既享低血奖励又让未来一直保持低血奖励。

## B-GATE｜相关STS1锚点及暂定风险

- 原版 `Hemokinesis`：1费、付2HP、15→20单体伤；本候选「余火一刺」14→17伤，但在蝶舞时可能得到额外加成，因此**未证明**整体更弱。https://www.slaythespire.gg/cards/ironclad/Hemokinesis
- 原版 `Shrug It Off`：1费、8→11格挡并抽1；「灯下定神」7→10并抽1，意在保留合理普通牌基准。https://www.slaythespire.gg/cards/ironclad/Shrug_it_Off
- 原版 `Iron Wave`：1费、5→7伤和5→7格挡；不可直接以“伤害+格挡”总点数判断保命或击杀优势。https://www.slaythespire.gg/cards/ironclad/Iron_Wave

已识别的待审风险：①HP支付可能使低血组合在所有常见情况下占优；②无即时回复时可能跨战迅速失血；③重击挂梅在护甲敌人上来源不足；④Q作为起始牌在群怪可能偏强，且战中共享12治疗额度不能证明长线可持续；⑤2阶段持续与抽到E的时机、升级价值待多牌序验证；⑥新牌和原版能力/状态/遗物交互未经实装测试。
