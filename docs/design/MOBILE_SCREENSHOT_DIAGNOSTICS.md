# 移动端截图式运行诊断（最小版）

## 用途
千星奇域手机真机无法假设具备 PC 编辑器日志、剪贴板、FPS 或内存 API。
优先使用外部设备测量真实 FPS、卡顿、CPU/GPU/温度，官方沙箱检测关卡负载。
本功能只帮助玩家在手机上 **截图 → 发给 AI** 定位游戏业务问题，不是性能分析器。

## 操作
1. 在本局内打开右上角「菜单」。
2. 点击「诊断报告」，截取包含版本、设备/画布、Run Seed、阶段、生命、战斗与输入状态的屏幕。
3. 关闭报告返回菜单，再继续本局。没有日志复制、自动上传、文件系统权限或后台采样。

## 实现边界
- 仅在原生退出/暂停布局中新增 diagnosticsPanel 和暂停菜单入口，无新贴图或逐帧属性更新。
- 数据从已有 GameUI/Run/BattleUI **只读** 取得，新增 Lua 模块只在打开时生成十行。
- 仅在 refresh() 时页面/阶段变化后记录最近三次转换，不进行逐帧日志字符串构建。
- 只标注 exitError；“none observed”不是全游戏零错误的证明。
- runSeed 与 codeVersion 可供 AI 关联版本和复现，但构建版本不是 Git commit SHA。
- “mobile”只能说明检测到触屏设备，不是具体手机型号。
- **绝不冒称真实 FPS、帧时间、系统内存、GPU 占用、设备型号或系统日志**。
- 面板有拦截背景输入的 blocker/catch，关闭后保持退出菜单，不触发结算/出牌。
- 旧测试布局无诊断面板时，运行时可以跳过初始化；正式候选生成的布局必须包含面板。

## 验收
- JS 原生控件结构检查 + Lua 真正执行的只读/容量/设备失败回退测试。
- 当前最终整合候选完成构建、真实 Simulator 截图、触屏/PC 开关报告、关闭、背景不透传及 20 次开合无泄漏；必须保存同候选截图。
- **手机官方客户端** 实测截图可读，留意刘海/安全区、纵横比与触摸命中。
- 本 PR 不改战斗规则、输入算术、日志/CI 超时，未取得官方客户端实测或正式发布许可前保持 Draft。
