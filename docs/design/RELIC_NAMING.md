# R-GATE v1.0｜遗物命名与文案准入

状态：2026-11-11 用户确认采用。适用于《杀戮原塔2》**玩家可见的遗物名称与效果文案**；继承技能 N-GATE 的来源核实、自然度、实际效果、角色气质、区分度原则，但遗物以“真实可持有的物品”为核心，不把技能名硬套进遗物。

## 评审原则

1. **先看实物与角色**：名称应像器物、晶石、护符、印记、纪念品等可持有之物；角色专属体现身份，通用遗物不强行附会元素。
2. **出处与适配分开**：优先查可用的《原神》官方物品与设定用语；官方出处只能证明来历，不证明适合本作机制。无合适官方名称时可原创，但不得冒称官方。
3. **语义吻合**：不用名称暗示不存在的属性、战斗触发或效果；进阶/替换关系优先保持同一器物意象。天然准确的通用名称（例如“日晷”“墨水瓶”）不为追求原创而改。
4. **自然且有辨识度**：中文读起来自然，避免僵硬拼词、过长故事短句、泛滥的“之心/之力”；同一遗物的各入口不得使用不同译名。
5. **效果与风味分层**：玩家功能描述明确触发时点、数值、限制与替换对象；风味文案可单独批准，但在 UI/Schema 未提供独立位置前不得塞入效果描述。
6. **审查最小范围**：命名 PR 必须说明来源、机制匹配、旧名/新名和受影响入口。未经明确审批不批量重写现有自然名称；不可因为文案变更修改内部 `id` / `sourceId` / `replaces`、效果、随机池和存档身份。

## 现存名称与后续评审

- 当前 `data/relics.json` 与 `abyss_relic_names.lua` 曾有20项名称冲突（如“船夹板/系缆桩”），本轮以**原玩家界面已使用的译名**统一定义名，而非创造20个新名字；补齐有本地定义但缺少来源 ID 解析的特殊遗物译名。
- 胡桃「引蝶灯」、阿蕾奇诺「炉火家书」、芙宁娜「留给自己的票根」、雷电将军「稻光军印」属于冻结的 `data/original_v4/rules_v4.json`。其中「留给自己的票根」存在审美疑虑，**登记为待评审，不在本轮擅自改写冻结包**。
- 其余遗物按玩家体验分批审查；无明显问题的不必改。

## 机械门禁（不是审美自动评分）

已有 `tests/relic-chinese-names.test.mjs` → `tests/lua/relic_chinese_names.lua` 进入标准 `npm test`：
- 全部已定义遗物的中文原始名等于实际 `abyss_relic_names.get(data,id)`；
- 带 `sourceId` 的遗物在没有定义表时仍返回相同中文名；显示名不能重复或混有英文占位；
- 已批准的两件保留稳定 ID、战斗结束治疗数值、替换关系与精确效果文案；
- 原有156个来源池身份、规则状态不变等既有检查照常执行。

这些机械规则只检出可验证的一致性问题，是否自然、贴合角色、符合作品风格仍由人工评审。游戏内/实体手机实际文字裁切须经正常 UI 验收，不由此文档宣称完成。
