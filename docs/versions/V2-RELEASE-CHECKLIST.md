## 哪些不在 v2.0.0 做

- **v2.0.1 · 中**：新页面非关键按钮、选角、切换、开箱等音效缺漏及上线后的小范围 Bugfix；复用 TASK-4、TASK-34。有声音缺失导致反馈不明确的 P0 仍在 2.0 解决。
- **v2.1.0 · 中**：经实机验收的新角色和独立构筑（TASK-85、59.3），不是本次加入。
- **v2.2.0 · 低**：第三幕、隐藏第四幕（TASK-62、64），不影响本次上线。
- **未绑定版本 · 低**：成就全量优化等仍处于探索/阻塞状态的项目（如 TASK-45），不因为“想一次做完”进入 2.0。

## 当前 GO / NO-GO 规则

**NO-GO（当前）**：三条关键 PR 仍 Open、未形成准确发行产物、完整 Full CI/官方导入/PC 和实体手机/官方容量证据未齐。屏幕永久等待、无法完成两幕、目标错误、误丢本局、关键 UI 不可操作、容量超限等也是直接阻断项。

只有 E30/E31/E33/E34 的高优先级门禁全部实测通过，并核对 E32 没有损害操作或可读性的严重退化，才能提出 GO。不能把某一 PR 的模拟器通过当作游戏已发布。先按已有 Backlog/CI 机制实施，不扩功能范围。所有验收证据必须绑定准确的 `source SHA + buildId + GIL SHA256 + payloadDigest`，官方发布成功后再更新 `data/release/publications.json`。
