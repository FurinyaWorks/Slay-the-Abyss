## 本轮范围

**必须可玩**：默认正式入口，岩系旅行者（单角色）；第一、二幕、跨幕本局状态、地图选路、战斗/奖励、宝箱、商店、营地、事件、遗物/药水、Boss、胜负与重开；已批准的 V25/原生 UI、选角和开场体验。玩法/来源概率不得为赶版擅自缩水。

## 5. 发布时的最小 Git 操作（仅示意，现阶段禁止执行）

从经发布 PR 进入 `master` 的已验收提交出发，检查 `master` 已含本轮所有批准改动且 Tag 尚不存在；必要时先清理本地陈旧 refs。只有在上面全数 P0 通过后：

```sh
git fetch origin --tags
git switch master
git pull --ff-only origin master
git tag -a v2.0.0 -m "Slay the Heavens v2.0.0 — verified release"
git push origin v2.0.0
```

**不要**现在对 `develop`、#661 的 HEAD 或 2026-11-14 的实验提交直接打 `v2.0.0`；不要使用 `git tag -f`。发布回执独立于 Git Tag 和 CI。
