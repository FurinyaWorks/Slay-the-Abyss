## 根因与有限修复

`abyss_merchant.lua` 原以 `page * pageCharacters` 为结束索引，完全不看句界。9 字模式开场首屏是“转过一道石廊，荧看”，下一屏从“到一块旧毯子”开始；12 字 official 投影也会拆开同一句。原文没有人为分页。固定 9/12 字预算、14 字号和两个文本框尺寸见 `source-reproduction.json`，该 JSON 是从当前源文本与旧算法导出的边界，不是截图或渲染容量测量。

新纯展示模块保存原字符的累计页面结束索引。优先句号/问号/叹号/显式换行；一整句超出现有预算时优先逗号/分号/冒号分段，没有可用边界再按预算回退。紧邻闭合引号与句末标点不单独甩到下一页，开引号不留在上一页。后一句能放入新页时保持完整；后一句连新页都装不下时允许把其前导短分句填入当前页，避免将“来，”单独分页。

不改文案、字号、9/12 字预算、人物/气泡几何、交易与反馈优先级，不使用自动缩字或截断。保留点击补全、继续、自动等待与收起、点击重读、隐藏暂停、购买反应即时替换。完整手动/自动阅读拼接仍严格等于原始文案。

这并不解决所有长句：例如没有标点且长于预算的句子仍必须分页。当前保守回退不代表 Owner 已批准最终语义规则。实际容量、标点行首效果、阅读时长及更合适的长句策略仍需同候选画面对照，不从字符上限推断原生字形测量。
