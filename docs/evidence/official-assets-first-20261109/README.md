# 官方原生素材候选实施与证据

本轮承接 PR #588 的官方素材优先合同。实现基于 #588 原始 `d7b44d21920fa1cdb4b3cb29047ac3a9e1b93c7e`，合入 #582 的精确生命周期基线 `06bc84ee4b2b3c7b51486df678ac4551ced1b084`，本地整合点 `520c44d4f8d9e8af93ab47e696331a4ff2eb45ab`。没有修改 #582 分支、生产 Lua 规则、数值或 RNG。#582 仍须按依赖门禁先行合并。

## 已实现入口

- `node scripts/build-ui.mjs <独立输出目录> --official-assets --native-page-lifecycle` 生成可检查的全部布局、主题与真实人物资产。此步骤不是 GIL 写入或官方导入。
- `npm run build:game -- <base.gil> <独立候选目录> --art-version=official` 接入现有正式候选构建/读回链；有声入口 `npm run build:native -- <base.gil> <独立候选目录> --official-assets` 保留同一官方配置与生命周期收据。当前环境尚未执行这两条原生写入命令。
- 官方候选明确独立 opt-in。`legacy`、`enhanced` 与默认构建不变；正式默认皮肤仍待同候选视觉验收。禁止与 release、V25 私有贴图、轻量样本、实验组件池或自定义 prepare 混用。
- 全部 60 个卡牌宿主统一使用官方底板，保留名称、描述、费用、稀有度、类型、状态、目标、命中区和现有运行路径。地图/菜单/选角/战斗/奖励/事件/商店共享同一布局变换，没有另造玩法框架。
- 复用 #582 的 `flat` 装饰及原生页面生命周期。结构检查确认移除 2940 个装饰控件，替换 202 个按钮表面及 15 个大面板；这些数字不是 GPU、加载时长或同画质性能改善数据。
- 完整候选、音频候选与审计重建均保留并验证官方配置；生成文件不能通过硬链接或符号链接覆盖新的配置/布局源文件。

## 验证边界

自动化测试调用真实 Host/Run/Combat 和生成的官方布局/主题，覆盖十张合法手牌、双敌、真实费用/伤害/回合、C 档点选、拖牌/取消/晚到输入、二十次非空抽弃牌堆往返及真实胜利领奖返回地图。Mock 只模拟平台控件和 readonly SetActive，并不会证明真实 SDK 的纹理加载或完整显示成本。另有 6 项全流程测试通过：生产双幕模式菜单→选角→Neow→自然首战→领奖回图；独立房间路由的商店预览/取消/购买、事件离开、满血营地禁休息与锻造、宝箱逐项领取；真实 boss 入口、拒绝提前跨幕/结算、敌方回合自然战败和重开。独立房间采用现有 campaign 组件模式，不冒充生产双幕自然路径。完整自然两幕通关、boss 胜利后跨幕、胜利结局与受伤后营地治疗尚未验证，不由直接修改状态冒充。

原回归第一次未通过的原因与恢复路径保留：测试工作树缺少四张冻结 LFS 预览，触发合法的输入哈希检查；使用现有 `prepareRuntimePreviews` 仅物化原有四个对象（181870 字节）后重测。音频测试夹具另需跟随真实 producer 保留 `uiProfile` 字段，生产校验没有放宽。第二轮 548 例中 525 通过、1 跳过、22 失败：20 例发现继承基线漏保护 `abyss_component_binding.lua` 输出，可通过别名改写数据；已补入保护清单，原断言保留。另外 2 例因稀疏工作树未物化 schema，补齐原文件后只复跑失败的 22 例，22/22 通过。初始无匹配 test-name-pattern 的文件级输出不计为断言通过。

最终串行官方测试 14/14 通过，每次绑定 685 项源码输入且前后未变；5 个受影响 CI 合同 62/62 通过。syntax、guidance、Backlog 与默认构建的每日 platform-load 检查均通过。独立源码复审和 CI 增量复审均无未解决代码问题，但不等于当前 HEAD 的 Full 或合并准入。

日志、测量、源文件哈希、独立复审分别留存于此目录；所有结论限定于各记录绑定的输入，不将旧日志冒称最新 SHA 的执行。
